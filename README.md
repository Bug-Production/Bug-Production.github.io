# Bug-Production.github.io

BugProduction organizasyonunun GitHub Pages sitesi.

- **Yayın adresi:** https://bug-production.github.io
- **Durum:** Placeholder / yapım aşamasında

## Yapı

| Dosya | Açıklama |
| --- | --- |
| `index.html` | Tek dosyalık placeholder sayfa (harici bağımlılık yok) |
| `.nojekyll` | GitHub Pages'in Jekyll işlemesini atlamasını sağlar |

## Yerelde çalıştırma

```bash
python -m http.server 8000
# http://localhost:8000
```

## Yayınlama

`main` dalına yapılan her push GitHub Pages tarafından otomatik yayınlanır.
